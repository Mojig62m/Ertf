# کتابخانه روش‌های اثبات‌شده و کمتر شناخته‌شده

روش‌هایی که در فاز بدون کد بیشترین اثر را دارند؛ کمتر متداول‌اند اما مستند و تکرارپذیرند.

| روش | چیست | کاربرد در این پروژه |
|---|---|---|
| Working Backwards / PR-FAQ (آمازون) | نوشتن خبرنامه و پرسش‌های متداول محصول فرضی پیش از ساخت | مرحله اول؛ آزمون واقعی ارزش پیشنهادی فروشگاه |
| پیش‌مرگ ذهنی (Gary Klein) | فرض شکست آینده و فهرست علل پیش از شروع | منبع ثبت ریسک؛ تکرار پایان هر مرحله |
| سوابق تصمیم معماری (Michael Nygard) | ثبت تغییرناپذیر تصمیم‌ها با زمینه و معیار بازبینی | ADR-0001 مصوب؛ الزام هر تصمیم مهم |
| Wardley Mapping | نقشه زنجیره ارزش و انتخاب ساخت/اجاره/خرید | تصمیم PSP، جست‌وجو، CDN و زیرساخت |
| Event Storming (DDD) | کشف رویدادها و مرزهای دامنه روی کاغذ | مرزبندی ماژول‌های سفارش، موجودی و پرداخت پیش از کد |
| STRIDE | مدل تهدید سیستماتیک برای هر جریان داده | امنیت مسیر پرداخت؛ نگاشت به ASVS |
| North Star Framework | یک شاخص واحد که تجربه، ارزش و سلامت را می‌سنجد | metrics-and-okr.md |
| Shape Up (Basecamp) | تعریف مسئله با اشتها و زمان محدود به‌جای برآورد باز | مرحله‌بندی نمونه و MVP |
| Diátaxis | چهار‌گانه آموزش/راهنما/ارجاع/توضیح برای مستندات | استاندارد نگارش مستندات مخزن |
| Real Options و Cost of Delay | خریدن گزینه تصمیم و تعویق تعهد پرهزینه | دروازه‌های اثبات سند راهبردی، بخش ۸ |
| Blameless Postmortem | تحلیل حادثه بدون سرزنش، با اقدام سیستمیک | مرحله ششم و هفتم؛ قالب مستقر از روز اول |
| Cynefin | تشخیص نوع مسئله (ساده/پیچیده/پیچیده/آشفته) برای انتخاب سبک تصمیم | چارچوبِ انتخاب روش تصمیم در گزارش‌های هفتگی |

هر روش پیش از استفاده، معیار خروجی و تاریخ بازبینی دارد؛ روش بدون خروجی، تشریفات است.

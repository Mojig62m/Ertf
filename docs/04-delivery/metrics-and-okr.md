# شاخص‌ها، درخت KPI و OKR

## North Star پیشنهادی (برای تأیید مالک)

تعداد سفارش‌های تکمیل‌شده ماهانه از خریدارانی که بدون نقص سفارش (خطای پرداخت، خطای موجودی، خطای رابط) به سرانجام رسیده‌اند. این شاخص، تجربه، صحت تراکنش و ارزش کسب‌وکار را هم‌زمان می‌سنجد.

## درخت KPI

- North Star: سفارش‌های سالم تکمیل‌شده
  - ترافیک و دسترس‌پذیری: بازدید، دسترس‌پذیری صفحه، Core Web Vitals
  - کشف و انتخاب: نرخ استفاده از جست‌وجو، نرخ کلیک نتایج، استفاده از فیلتر
  - تبدیل: نرخ تبدیل سبد به سفارش، رهاکردن سبد، رد شدن در پرداخت
  - صحت: خطای پرداخت، ناسازگاری موجودی، تکرار سفارش
  - وفاداری: بازگشت مشتری، نرخ مرجوعی

## سنجه‌های تحویل نرم‌افزار — پژوهش DORA

برای اثبات عملکرد تحویل، از مرحله دوم (نخستین کد) سنجه‌های DORA در کنار شاخص‌های کسب‌وکار پایش می‌شوند: بسامد استقرار، زمان پیشروی تغییر، زمان بازیابی استقرار شکست‌خورده، نرخ شکست تغییر، نرخ دوباره‌کاری، و قابلیت اطمینان. مطابق هشدار رسمی DORA، این سنجه‌ها فقط در سطح سیستم برای یادگیری به‌کار می‌روند، هرگز برای ارزیابی عملکرد افراد. مقادیر هدف پس از نخستین دو هفته داده واقعی تعیین و در ADR ثبت می‌شوند.

## OKR مرحله اول

- هدف: تثبیت نیازمندی‌ها با کیفیت تصمیم قابل‌دفاع.
- نتیجه ۱: پاسخ مستند به تمام پرسش‌های باز PRD.
- نتیجه ۲: ADR مصوب پرداخت و ارسال.
- نتیجه ۳: معیار پذیرش آزمون‌پذیر برای هر سناریوی سفر خرید.

## اهداف فنی

- Core Web Vitals در صدک ۷۵: مطابق سند راهبردی، بخش ۷.
- اهداف تأخیر API، ظرفیت و دسترس‌پذیری: پس از انتخاب زیرساخت در مرحله دوم با سنجش نمونه تعیین و در ADR ثبت می‌شوند.
- پیشنهاد اولیه برای پذیرش: بودجه خطای ۰٫۵ درصد در ماه (دسترس‌پذیری حدود ۹۹٫۵) برای تأیید مالک.

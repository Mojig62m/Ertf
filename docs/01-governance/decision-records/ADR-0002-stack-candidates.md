# ADR-0002: نامزدهای فنی اولیه

وضعیت: پیشنهادی — تأیید نهایی پس از نمونه عملی مرحله دوم

## زمینه

سند راهبردی استک نامزدی را تعریف کرده است؛ اما اصل پروژه، تصمیم مبتنی بر شواهد است، نه انتخاب پیش از آزمون.

## تصمیم

نامزدهای اولیه: Astro برای صفحات، Svelte یا Preact برای رابط‌های تعاملی، Hono و TypeScript برای API، PostgreSQL به‌عنوان منبع حقیقت، دسترسی SQL شفاف با ارزیابی Drizzle در صورت اثبات ارزش. TanStack Start به‌عنوان گزینه تمام‌پشته در صورت غالب‌شدن تعاملات پیچیده بررسی می‌شود.

## معیارهای مقایسه برابر (نمونه مرحله دوم)

- عملکرد: Core Web Vitals در صدک ۷۵ روی دستگاه‌های هدف
- تجربه توسعه: زمان پیاده‌سازی مسیر کامل خرید در نمونه
- سازگاری زیرساخت و هزینه نگهداری تخمینی

## بازبینی

پایان مرحله دوم، با داده سنجش نمونه. نتیجه در ADR-0003 ثبت خواهد شد.

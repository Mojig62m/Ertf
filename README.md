## اصول حاکم بر مخزن

۱. هر تصمیم مهم، یک ADR دارد؛ بدون ADR، تصمیم معتبر نیست.
۲. هر ادعای بیرونی، منبع ارجاع‌پذیر دارد.
۳. هر ریسک، مالک و اقدام کاهشی دارد.
۴. هیچ تغییری بدون معیار پذیرش نوشته‌شده انجام نمی‌شود.
۵. PostgreSQL منبع حقیقت است؛ مستندات و کد هم از همین اصل پیروی می‌کنند.

## وضعیت

- فاز: مرحله دوم — نمونه فنی محدود؛ **سخت‌سازی go-live انجام شد** (قدم ۱ تا ۶)
- پیشرفت: اسکلت، پایگاه داده و seed، API، صفحات و جزایر، سبد و تسویه شبیه‌سازی‌شده، لایه پرداخت مستقل از تأمین‌کننده (شبیه‌سازی فعال، زرین‌پال مرحله سوم)
- **سخت‌سازی استقرار (اکتوبر ۲۰۲۶):** رفع آسیب‌پذیری بحرانی با ارتقا به Astro 7 (ADR-0005)، قفل وابستگی‌ها با lockfile، تایپ‌چک سبز (`astro check`)، حذف fallback راز `DATABASE_URL`، مهاجرت‌های نسخه‌دار Drizzle، Dockerfile چندمرحله‌ای غیر root، probe آمادگی دیتابیس، لاگ ساختاریافتهٔ JSON، Server Islands و پیش‌واکشی هوشمند، اصلاح CI (حذف پوش خودکار به main + افزودن check/audit/CodeQL/Dependabot)
- قدم ۶: اجرای اثباتی در گردش‌کار GitHub Actions؛ خروجی سنجش به‌صورت artifact بارگذاری می‌شود (دیگر کامیت خودکار به main انجام نمی‌شود)
- باقی‌مانده: تحلیل نتیجه گردش‌کار، تکمیل گزارش سنجش میدانی CWV، Go/No-Go مرحله سوم
- سیستم عامل ایجنت: نسخه ۲٫۲ — نخبگی اجرایی با پایه شواهد علمی (نصب‌شده)
- تصمیم میزبانی مالک: تولید کاملاً درون‌کشوری؛ نمونه محلی و اثبات در زیرساخت ابری GitHub Actions
- تصمیم رانتایم (ADR-0005): Node LTS + درز قابلیت جابه‌جایی Web-API
- باقی‌مانده حاکمیتی: تأیید نهایی نام برند و ثبت ertf.com (پیش‌نیاز اینماد، R15 و R03)، تکمیل ثبت مالیاتی (R17)، سقف ارسال رایگان، تأیید نهایی مجوز مخزن (MIT در برابر اختصاصی)
- راهنمای اجرای نمونه و استقرار: app/README.md

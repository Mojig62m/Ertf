## اصول حاکم بر مخزن

۱. هر تصمیم مهم، یک ADR دارد؛ بدون ADR، تصمیم معتبر نیست.
۲. هر ادعای بیرونی، منبع ارجاع‌پذیر دارد.
۳. هر ریسک، مالک و اقدام کاهشی دارد.
۴. هیچ تغییری بدون معیار پذیرش نوشته‌شده انجام نمی‌شود.
۵. PostgreSQL منبع حقیقت است؛ مستندات و کد هم از همین اصل پیروی می‌کنند.

## وضعیت

- فاز: مرحله دوم — نمونه فنی محدود (قدم ۱ تا ۵ انجام شد؛ در انتظار سنجش مالک)
- پیشرفت: اسکلت، پایگاه داده و seed، API، صفحات و جزایر، سبد و تسویه شبیه‌سازی‌شده، لایه پرداخت مستقل از تأمین‌کننده (شبیه‌سازی فعال، زرین‌پال مرحله سوم)
- باقی‌مانده: قدم ۶ سنجش Core Web Vitals توسط مالک (قالب: docs/04-delivery/cwv-measurement-report.md)، قدم ۷ ADR-0005 و Go/No-Go مرحله سوم
- سیستم عامل ایجنت: نسخه ۲٫۲ — نخبگی اجرایی با پایه شواهد علمی (نصب‌شده)
- تصمیم میزبانی مالک: تولید کاملاً درون‌کشوری؛ نمونه محلی
- باقی‌مانده حاکمیتی: تأیید نهایی نام برند و ثبت ertf.com (پیش‌نیاز اینماد، R15 و R03)، تکمیل ثبت مالیاتی (R17)، سقف ارسال رایگان
- راهنمای اجرای نمونه: app/README.md

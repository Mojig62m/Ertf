# Ertf — پروژه فروشگاه آنلاین

این مخزن، خانه رسمی سند راهبردی، حاکمیت، الزامات محصول و برنامه اجرای پروژه فروشگاه آنلاین است. نام برند موقت: ارتِف (Ertf) — طبق ADR-0004.

فاز فعلی پروژه صریحاً «بدون کد» است: تا پایان مرحله اول و دوم، هیچ کدی تولید نمی‌شود؛ همه خروجی‌ها مستند، تصمیم، معیار و برنامه قابل‌بررسی هستند. این اصل، تکرارپذیری تصمیم‌ها و قابلیت بازگشت را پیش از هرگونه سرمایه‌گذاری فنی تضمین می‌کند.

## اصول حاکم بر مخزن

۱. هر تصمیم مهم، یک ADR دارد؛ بدون ADR، تصمیم معتبر نیست.
۲. هر ادعای بیرونی، منبع ارجاع‌پذیر دارد.
۳. هر ریسک، مالک و اقدام کاهشی دارد.
۴. هیچ تغییری بدون معیار پذیرش نوشته‌شده انجام نمی‌شود.
۵. PostgreSQL منبع حقیقت است؛ مستندات هم از همین اصل پیروی می‌کنند.

## وضعیت

- فاز: مرحله دوم — نمونه فنی محدود (در حال اجرا؛ برنامه مصوب در docs/04-delivery/prototype-plan-phase2.md)
- سیستم عامل ایجنت: نسخه ۲٫۲ — نخبگی اجرایی با پایه شواهد علمی (نصب‌شده)
- استک نمونه (تحلیل ایجنت): Astro + جزایر Svelte + Hono + PostgreSQL با ارزیابی Drizzle؛ پرداخت شبیه‌سازی‌شده؛ ۵۰ محصول نمونه؛ اجرای محلی
- تصمیم میزبانی مالک: تولید کاملاً درون‌کشوری؛ نمونه محلی
- باقی‌مانده حاکمیتی: تأیید نهایی نام برند و ثبت ertf.com (پیش‌نیاز اینماد، R15 و R03)، تکمیل ثبت مالیاتی (R17)، سقف ارسال رایگان (وابسته به داده قیمت)
- گام بعدی ایجنت: اجرای برنامه کار مرحله دوم، قدم یک تا هفت؛ نتیجه نهایی در ADR-0005
